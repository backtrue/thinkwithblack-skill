# MK-136｜FABE Copy Gap Check

For a regular chat, upload `packs/mk-136.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Missing or inconsistent elements among the four components**

Creating a draft from scratch here does not automatically invoke Speak Human TW; when editing an existing draft, read its original instructions only if that proofreading need clearly applies

## Required Inputs

Copy to inspect, product facts, Persona, alternative comparisons and available evidence

## Method Steps

1. Check each section for an actual Feature, Advantage, Benefit, and Evidence
2. If Advantage is missing, return to comparison with alternatives; if Benefit is missing, return to the Persona; if Evidence is missing, label the evidence gap
3. Do not have the model invent competitor weaknesses, effect sizes, or nonexistent proof to fill all four cells

## Calculation and Interpretation

First verify product facts and creative usage rights; check current platform character counts, aspect ratios, and restrictions when producing the creative

## Verification Cases

**MK-136-C05｜Data meets existing conditions**

Expected: report usable or keep as is; do not invent a need for changes

**MK-136-C06｜The tool returns an error**

Expected: report data not obtained; do not classify the tool error as a business anomaly
