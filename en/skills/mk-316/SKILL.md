# MK-316｜Choose Page Types for Search Demand

For a regular chat, upload `packs/mk-316.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Fit with article, comparison, category, or booking pages**

Permission in robots or the existence of a sitemap does not guarantee indexing; do not combine site technical status and content quality into a single conclusion

## Required Inputs

Provide: website pages, HTML, existing content, audiences, and search demand

## Method Steps

1. Choose page types by the four Search Intents: informational → education/explanation/guide; navigational → brand/official site/specified entry; commercial investigation → comparison/testimonials/differences; transactional → booking/purchase/information request
2. Do not send every search about the same topic to one page
3. If intent is unclear, leave it for validation rather than force a page type based on identical keywords

## Calculation and Interpretation

Actually crawl/read content and site structure; check current rules and markup, without promising rankings or citations
