# MK-139｜Benefit-Led Headline

For a regular chat, upload `packs/mk-139.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Headlines supported by product facts**

Creating a draft from scratch here does not automatically invoke Speak Human TW; when editing an existing draft, read its original instructions only if that proofreading need clearly applies

## Required Inputs

Confirmed Persona, three USPs/evidence, product facts and ad context; provide existing copy when available, or use these inputs to draft from scratch

## Method Steps

1. Prioritize the Persona's value proposition in the ad headline rather than only the product name or specifications
2. Translate product features into a benefit or change the Persona cares about
3. Build the value proposition on the confirmed USP + Persona; revisit the headline whenever either changes

## Calculation and Interpretation

First verify product facts and creative usage rights; check current platform character counts, aspect ratios, and restrictions when producing the creative
