# MK-146｜Call-to-Action Clarity Check

For a regular chat, upload `packs/mk-146.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Clarity of the action, audience, and purpose**

Creating a draft from scratch here does not automatically invoke Speak Human TW; when editing an existing draft, read its original instructions only if that proofreading need clearly applies

## Required Inputs

CTA wording/location, intended action/campaign goal, destination or flow content, real eligibility/offer conditions

## Method Steps

1. There is no single best CTA; test additional options according to the current objective
2. The CTA must match the destination and campaign objective, such as the website, messaging, or another specified action
3. Do not add a CTA scoring formula absent from the course; focus on clarity and an executable action

## Calculation and Interpretation

First verify product facts and creative usage rights; check current platform character counts, aspect ratios, and restrictions when producing the creative

## Verification Cases

**MK-146-C05｜Data meets existing conditions**

Expected: report usable or keep as is; do not invent a need for changes

**MK-146-C06｜The tool returns an error**

Expected: report data not obtained; do not classify the tool error as a business anomaly
