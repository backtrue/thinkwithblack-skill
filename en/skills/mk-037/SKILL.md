# MK-037 | Information-gap assessment

For a regular chat, upload `packs/mk-037.md`. It includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Information each need still requires before action**

Task stages are analytical categories, not a claim that every customer follows the same path

## Required inputs

Provide: The product or service, customers' own words, existing pages, and actions the company can support

## Method

1. For every search/path, mark the points that are currently only inferred
2. Focus on whether the customer problem is real, the recommended page actually exists, and the customer would actually want to take the next step
3. If evidence is missing, mark "insufficient evidence"; do not invent stories to fill the table

## Calculations and interpretation

Search phrases and paths are planning hypotheses; check them against real search terms and evidence of how pages support the need
