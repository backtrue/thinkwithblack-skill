# MK-187｜Remarketing Repeated-Reach Check

For a regular chat, upload `packs/mk-187.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Risks from audience overlap and excessive messaging**

Event groups do not necessarily represent the same people dropping off at each stage; verify counting and attribution across data sources

## Required Inputs

Provide: the event funnel, pages, existing audiences, and actual offer terms

## Method Steps

1. Remarketing centers on providing different reasons to buy at different stages, not unlimited repeated exposure
2. First use exclusions to prevent purchasers from continually seeing nonbuyer creative, then check whether the same person belongs to multiple overlapping audiences
3. The original course provides no fixed Frequency cap or exposure threshold, so do not invent one; if account Frequency is readable, use it as actual monitoring data

## Calculation and Interpretation

Verify source periods, audience overlap, and exclusions; funnel changes alone do not prove psychological causes
