# MK-253｜Product Description Completeness Check

For a regular chat, upload `packs/mk-253.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Missing information about features, uses, and limitations**

When IDs cannot be matched one-to-one, leave them unmatched rather than guess; do not invent a match rate without complete event samples

## Required Inputs

Provide: product Feed, actual website information, SKU performance, and disapproval messages

## Method Steps

1. Use an actual product description for description, sufficient at least for the catalog to understand the product
2. Do not include nonexistent features, results, or offers
3. The original course specifies no fixed length/template; check that a value exists, matches the product, and is usable by the catalog

## Calculation and Interpretation

Use product data for specifications and prices; verify catalog fields and disapproval rules during production

## Verification Cases

**MK-253-C05｜Data meets existing conditions**

Expected: report usable or keep as is; do not invent a need for changes

**MK-253-C06｜The tool returns an error**

Expected: report data not obtained; do not classify the tool error as a business anomaly
