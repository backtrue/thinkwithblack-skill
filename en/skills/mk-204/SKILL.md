# MK-204｜Post ID Identification

For a regular chat, upload `packs/mk-204.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Traceable post identifiers and format checks**

Past success supports candidates and hypotheses only; shared content elements are not proven causes of success

## Required Inputs

Complete post URL, preview/original link, content type and identifiable source; a known Post ID may aid checking but is not required

## Method Steps

1. Use Post ID as the core Hero Post identifier; do not substitute an ad name
2. Use the supplied post URL or preview screenshot; identify the ID from /posts/, story_fbid, or a video URL
3. The video identifier in a video URL must be used according to the actual platform workflow; check the current interface before actual execution

## Calculation and Interpretation

Preserve identifiers as original strings and verify the associated Page and post; record video IDs, candidate IDs, and confirmed Post IDs separately, leaving unverified platform mappings pending

| 4 | Format check result | Use the supplied source, calculation, or explicit unknown |

## Verification cases

**MK-204-A1 | Only a post URL containing /posts/**

Expected: Identify candidate ID from the source, without requiring it first

**MK-204-A2 | Only a video identifier**

Expected: Retain content type/required conversion check, not a presumed post ID
