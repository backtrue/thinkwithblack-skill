# MK-310｜Build a Search Answer Matrix

For a regular chat, upload `packs/mk-310.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **A mapping of audiences, stages, questions, and pages**

Permission in robots or the existence of a sitemap does not guarantee indexing; do not combine site technical status and content quality into a single conclusion

## Required Inputs

Provide: website pages, HTML, existing content, audiences, and search demand

## Method Steps

1. Organize audience × Search Intent × user question into an answer matrix
2. For each question, mark the recommended page type, page task, and status: exists / can improve / needs a new page
3. Finally identify missing decision stages, overlooked audiences, and whether key hub pages are needed

## Calculation and Interpretation

Actually crawl/read content and site structure; check current rules and markup, without promising rankings or citations
