# MK-163｜Meta Audience Hypothesis List

For a regular chat, upload `packs/mk-163.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Audience evidence and reasons for testing**

Use actual tools and current official specifications to establish platform options and placement availability; old course screenshots do not establish current capabilities

## Required Inputs

Persona or customer evidence, product capabilities/limits, need context and business purpose; corresponding conversion data only when used

## Method Steps

1. Build audience hypotheses from the Persona: demographics, purchasing power, interests, frequented brands/places, and everyday behavior
2. Choose labels that describe the person, not the product name itself; selling steak does not mean automatically selecting steak
3. Use one clear audience hypothesis per ad set rather than mixing all labels into one group
4. After the account has conversion data and has run ads for some time, consider more automation through ADV+; do not treat full automation as an unconditional default for a new account without data

## Calculation and Interpretation

Verify current platform settings and available audiences; this catalog does not establish an existing account read/write integration
