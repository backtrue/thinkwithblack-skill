# Persona interest reference guide

Use an available list supplied for the task. Retain each original label, category, source URL and snapshot date; list reading translations separately and leave current platform availability unverified

## Source guide

- [Eachspy interest catalog](https://www.eachspy.com/facebook-ads-interests/); historical reference date: 2026-09-23. [Section 2 of its terms](https://www.eachspy.com/terms/) requires permission to republish data; this open-source package retains source navigation
- [Primenumbers reference request page](https://primenumbers.co.jp/download/meta_interesting/); historical reference date: October 2026. Obtain data from its provider and follow the applicable use conditions

## Input format

| Original label | Category or description | Source | Snapshot date | Permitted scope |
|---|---|---|---|---|
| Actual supplied label | Original category | Original URL or supplied file | Known date or unknown | Conditions applicable to this task |

If a list is missing or unreadable, organize the known Persona traits and gaps first; select labels once the list is available. Do not invent platform labels from memory
