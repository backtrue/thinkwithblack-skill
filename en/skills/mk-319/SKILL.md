# MK-319 | Page H1 Hierarchy Check

For ordinary chat, upload `packs/mk-319.md`, which includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Issues with topic structure and heading hierarchy**

Permission in robots or the presence of a sitemap does not guarantee indexing; do not combine technical website status and content quality into one conclusion

## Required inputs

Provide: website pages, HTML, existing content, audience, and search needs

## Method steps

1. Check whether the main H1 clearly defines the main question / page topic
2. Add explanatory paragraphs below the H1; placing an input field / button directly after a heading leaves the semantic chunk incomplete
3. Subsequent H2 headings should support the H1 topic

## Calculation and interpretation

Actually crawl and read the content and website structure; check current rules and markup, without guaranteeing rankings or citations
