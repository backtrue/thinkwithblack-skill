# MK-033 | Separating events from personality descriptions

For a regular chat, upload `packs/mk-033.md`. It includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Abstract labels rewritten as verifiable events**

Task stages are analytical categories, not a claim that every customer follows the same path

## Required inputs

Provide: The product or service, customers' own words, existing pages, and actions the company can support

## Method

1. An event description must state something observable that happens, not a personality label such as "values quality" or "likes looking good"
2. If a description cannot answer "What happened?", return to the event level and rewrite it
3. Do not substitute Persona traits for evidence of a need trigger

## Calculations and interpretation

Search phrases and paths are planning hypotheses; check them against real search terms and evidence of how pages support the need

**MK-033-C05 | An ad promotes a service that the page does not explain**
