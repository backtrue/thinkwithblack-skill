# MK-142｜Adapt One Selling Point Across Audiences

For a regular chat, upload `packs/mk-142.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Facts preserved while situations and benefits are adapted**

Creating a draft from scratch here does not automatically invoke Speak Human TW; when editing an existing draft, read its original instructions only if that proofreading need clearly applies

## Required Inputs

Original USP/evidence, existing draft or value proposition, each audience’s known context/problems and product facts

## Method Steps

1. Rewrite the same USP into different value propositions and situations for different Personas
2. Keep product facts unchanged; change only the Persona's language, concerns, and Benefit
3. Test Persona versions separately; do not mix every Persona's labels and messaging into one ad set

## Calculation and Interpretation

First verify product facts and creative usage rights; check current platform character counts, aspect ratios, and restrictions when producing the creative
