# MK-320 | Page H2 and H3 Structure Check

For ordinary chat, upload `packs/mk-320.md`, which includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Issues with question-and-answer hierarchy and paragraph relationships**

Permission in robots or the presence of a sitemap does not guarantee indexing; do not combine technical website status and content quality into one conclusion

## Required inputs

Provide: website pages, HTML, existing content, audience, and search needs

## Method steps

1. Use H1→H2→H3 to create understandable sections; H1 is the main question, while H2 headings are smaller, answerable questions
2. For AEO, prioritize H2 headings that resemble user queries, with the answer immediately below each H2
3. Do not add headings just to include keywords; every heading must correspond to an actual content chunk

## Calculation and interpretation

Actually crawl and read the content and website structure; check current rules and markup, without guaranteeing rankings or citations
