# MK-252｜Product Title Identifiability Check

For a regular chat, upload `packs/mk-252.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Missing brand, model, and core attributes**

When IDs cannot be matched one-to-one, leave them unmatched rather than guess; do not invent a match rate without complete event samples

## Required Inputs

Provide: product Feed, actual website information, SKU performance, and disapproval messages

## Method Steps

1. Use the actual product name for title so the catalog and ads can identify it
2. Titles must map one-to-one to SKUs/product pages; avoid many identical generic names that create confusion
3. The original course provides no SEO title formula; check only identifiability and data consistency without adding rules

## Calculation and Interpretation

Use product data for specifications and prices; verify catalog fields and disapproval rules during production
