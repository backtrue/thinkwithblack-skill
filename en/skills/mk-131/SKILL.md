# MK-131｜Sales Page Evidence Gap Check

For a regular chat, upload `packs/mk-131.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Missing sources, false testimonials, and vague guarantees**

A page content check does not replace user behavior data; without performance data, do not assert the cause of declining conversions

## Required Inputs

Actual page claims/locations, product facts, existing testimonials/evidence sources and audience-need evidence

## Method Steps

1. Verify that third-party testimonials exist and can be checked, including authentic reviews, ordinary user experiences, media, awards/certifications, and similar sources
2. Check whether the feature benefits in cells four–six are supported by product facts, rather than only the brand's own claims
3. If the main pain point or selling point is still a brand hypothesis, identify the need for a questionnaire or other first-party data; do not turn it into a consumer fact

## Calculation and Interpretation

Quotes, numbers, effects, and testimonials require original support; produce page drafts only, without automatic publication

## Verification Cases

**MK-131-C05｜Data meets existing conditions**

Expected: report usable or keep as is; do not invent a need for changes

**MK-131-C06｜The tool returns an error**

Expected: report data not obtained; do not classify the tool error as a business anomaly
