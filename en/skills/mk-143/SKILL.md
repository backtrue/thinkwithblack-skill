# MK-143｜Ad Primary Text and Destination Alignment

For a regular chat, upload `packs/mk-143.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Consistency between ad promises and destination pages**

Creating a draft from scratch here does not automatically invoke Speak Human TW; when editing an existing draft, read its original instructions only if that proofreading need clearly applies

## Required Inputs

Actual primary text, headline and creative, intended action, destination content/URL, product/offer facts

## Method Steps

1. Use three-line primary text, adding long-form FABE when necessary; use the Persona's value proposition for the headline
2. Usually direct traffic to the website using a link with tracking parameters; use another destination only when that is the actual objective
3. Keep the copy's promise, creative, and destination page consistent; the page must deliver on the ad's message

## Calculation and Interpretation

First verify product facts and creative usage rights; check current platform character counts, aspect ratios, and restrictions when producing the creative
