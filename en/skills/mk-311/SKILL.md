# MK-311｜Topic Hub Page Planning

For a regular chat, upload `packs/mk-311.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **A hub blueprint that answers a set of needs together**

Permission in robots or the existence of a sitemap does not guarantee indexing; do not combine site technical status and content quality into a single conclusion

## Required Inputs

Provide: website pages, HTML, existing content, audiences, and search demand

## Method Steps

1. Identify topics suited to a hub page: a single topic has multiple readiness levels/intents requiring paths to different pages
2. Define the hub's core task, necessary content modules, child pages, and questions to answer
3. A hub page is more than a long article; it helps people with different intents find the correct next step

## Calculation and Interpretation

Actually crawl/read content and site structure; check current rules and markup, without promising rankings or citations
