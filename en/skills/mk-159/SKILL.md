# MK-159｜Evergreen Trust Asset Classification

For a regular chat, upload `packs/mk-159.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Classification by audience, concern, and stage**

Use actual tools and current official specifications to establish platform options and placement availability; old course screenshots do not establish current capabilities

## Required Inputs

Provide: actual reviews, customer service records, collaboration content, permissions, and performance data

## Method Steps

1. Classify evergreen trust assets into user testimonials, third-party reviews/KOL KOC, professional authorities, customer service Q&A, and similar types
2. Preserve each asset's source and permission status so remarketing can select it for different concerns
3. User testimonials and celebrity/authority endorsements are not mutually exclusive; test them in parallel according to the product's trust needs

## Calculation and Interpretation

Use only authentic reviews and third-party content with usage rights; do not fabricate reviews, endorsements, or engagement
