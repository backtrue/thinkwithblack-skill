# MK-404 | LINE Stage Tag Design

For ordinary chat, upload `packs/mk-404.md`, which includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Statuses for joining, consideration, first purchase, and repeat purchase**

Do not send messages or create automation without approval; if a tool cannot show recipient eligibility, do not assume everyone can be messaged

## Required inputs

Provide: friend or subscriber status, permissions, product content, campaigns, and channel reports

## Method steps

1. Stage tags can distinguish at least newly joined, considering, purchased, and statuses such as repeat purchaser / dormant / VIP
2. Stage tags manage status rather than permanent personality traits; update them when customer behavior changes
3. Each stage has a different message task: education + first purchase, trust reinforcement, usage guidance + repeat purchase, new products / exclusive offers, reactivation, or cleanup

## Calculation and interpretation

Verify contact consent, unsubscribes, and message specifications; friend counts and open rates are not sales
