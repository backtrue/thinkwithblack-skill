# MK-134｜Sales Page Single-Variable Test Design

For a regular chat, upload `packs/mk-134.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **One key difference compared per test**

A page content check does not replace user behavior data; without performance data, do not assert the cause of declining conversions

## Required Inputs

Provide: product facts, Persona, selling points, authentic evidence, offers, and brand information

## Method Steps

1. Individual cells allow an A/B Test of a specific page section without rebuilding the whole page each time
2. Replace only the cell being tested, such as the first cell's positioning, second cell's pain point, three core features, or testimonials
3. If the main pain point or selling point is unknown, first collect first-party data through a questionnaire-based warm-up, then decide what to test
4. The original course provides no fixed sample size, statistical significance threshold, or stopping rule; do not invent these as course rules

## Calculation and Interpretation

Quotes, numbers, effects, and testimonials require original support; produce page drafts only, without automatic publication
