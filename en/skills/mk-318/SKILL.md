# MK-318 | Page Meta Description Check

For ordinary chat, upload `packs/mk-318.md`, which includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Descriptions that match the actual page**

Permission in robots or the presence of a sitemap does not guarantee indexing; do not combine technical website status and content quality into one conclusion

## Required inputs

Provide: website pages, HTML, existing content, audience, and search needs

## Method steps

1. Check whether a Meta Description exists and serves as the page introduction / first impression
2. Keep the description consistent with the title, H1, and page content; do not make promises that the page does not support
3. The original course materials specify neither a fixed character count nor a ranking guarantee; do not invent hard rules

## Calculation and interpretation

Actually crawl and read the content and website structure; check current rules and markup, without guaranteeing rankings or citations
