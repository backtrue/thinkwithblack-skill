# MK-144｜Feed Creative Adaptation

For a regular chat, upload `packs/mk-144.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Image and copy drafts suited to the reading context**

Creating a draft from scratch here does not automatically invoke Speak Human TW; when editing an existing draft, read its original instructions only if that proofreading need clearly applies

## Required Inputs

Source asset/readable layout, core Persona value proposition/USP, feed-placement context and confirmed specifications

## Method Steps

1. Follow the course by using a square version for Facebook feed creative
2. Retain the core value proposition and USP when adapting the same creative; cropping must not change the message
3. Do not assume a square asset is the best Stories/Reels version; prepare dimensions separately for different placements

## Calculation and Interpretation

First verify product facts and creative usage rights; check current platform character counts, aspect ratios, and restrictions when producing the creative
