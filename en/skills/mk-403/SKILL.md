# MK-403 | LINE Customer Problem Tag Design

For ordinary chat, upload `packs/mk-403.md`, which includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Customer problems that change subsequent messages**

Do not send messages or create automation without approval; if a tool cannot show recipient eligibility, do not assume everyone can be messaged

## Required inputs

Provide: friend or subscriber status, permissions, product content, campaigns, and channel reports

## Method steps

1. Problem tags record the pain points / needs a friend is trying to solve
2. Create a tag only if it changes subsequent content, recommendations, or the service path
3. Problems must come from actual replies, quizzes, or behavioral evidence; do not put model guesses directly into customer tags

## Calculation and interpretation

Verify contact consent, unsubscribes, and message specifications; friend counts and open rates are not sales
