# MK-405 | LINE Tag Simplification Check

For ordinary chat, upload `packs/mk-405.md`, which includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Tags without corresponding business actions**

Do not send messages or create automation without approval; if a tool cannot show recipient eligibility, do not assume everyone can be messaged

## Required inputs

Provide: Current tags and definitions, trigger sources, usage history, downstream messages/automation references and verifiable data keys

## Method steps

1. More tags are not always better; retain only those that determine subsequent messages and business actions
2. The course materials' 7-day action list suggests starting with the 5–8 most necessary tags
3. Merge duplicate / synonymous tags and remove categories with no downstream use

## Calculation and interpretation

Verify contact consent, unsubscribes, and message specifications; friend counts and open rates are not sales
