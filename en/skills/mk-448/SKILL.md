# MK-448 | Consulting Response Evidence Check

For ordinary chat, upload `packs/mk-448.md`, which includes the shared rules, this method, and required references

## Purpose

This skill delivers: **Checks of whether claims cite data actually obtained**

Maintain, observe, and gather evidence first are valid decisions; do not conceal a lack of evidence behind a well-organized report

## Required inputs

Provide: brand background, existing data, course rules, and the current decision

## Method steps

1. Each consulting output lists preliminary judgment, supporting data, main problems, corresponding course logic, priority recommendations, and additional data needed next
2. Recommendations must identify the page and module to improve and explain their priority
3. Label insufficient data as such; do not fill the gap with abstract SEO advice or model guesses

## Calculation and interpretation

This task only inventories work; old specifications are not new authorization, and tools must actually be available before claiming execution
