# MK-145｜Vertical Creative Adaptation

For a regular chat, upload `packs/mk-145.md`; it includes the shared rules, this method, and required references

## Purpose

This Skill delivers: **Drafts reorganized for vertical viewing**

Creating a draft from scratch here does not automatically invoke Speak Human TW; when editing an existing draft, read its original instructions only if that proofreading need clearly applies

## Required Inputs

Provide: product, audience hypothesis, evidence, landing page, and placement requirements

## Method Steps

1. Use vertical creative for Instagram/Facebook Reels and Stories
2. Preserve the core Persona value proposition and USP, and rearrange the layout rather than merely auto-cropping
3. The course explicitly rejects one size for every placement; create a separate square version when feed placement is needed

## Calculation and Interpretation

First verify product facts and creative usage rights; check current platform character counts, aspect ratios, and restrictions when producing the creative
