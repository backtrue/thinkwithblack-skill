# Contributing

When reporting an issue, include the materials version, method ID, reproducible fictional or anonymized data, the actual result and the expected result

When revising a method, preserve its complete steps, source locations and required references. For a new source, identify the step it supports. Clearly label hypothetical examples. The free edition uses user-supplied data to complete one clearly defined task

Chinese and English methods share the same IDs and filenames. Review the corresponding source and translation together, including formulas, conditions, output fields and references

Maintainers update method sources and the relevant `free-content.json`, then run the generation and verification commands in [RELEASE.md](RELEASE.md). Packs, indexes and catalogs are generated files. Update the source-version record only after reviewing the corresponding translation
