# MK-353 | Off-Site Content Collaboration List


## Purpose

This skill delivers: **Real URLs, topics, and reasons to collaborate**

Brand mentions, citations, and correct descriptions are different outcomes and cannot substitute for one another

## Required inputs

Provide: brand information, the official website, off-site mentions, media coverage, and search results

## Method steps

1. Start with the SERP to examine the external citation landscape; inventory worthwhile positions in media, forums, blogs / KOL content, third-party comparisons / recommendations, video, and other formats
2. Decide for each position whether to publish yourself, collaborate, or provide information; prioritize contexts already offering visibility, credibility, and opportunities for AI citation
3. This is not a backlink shopping list; explain the role each position plays in the information used to form answers

## Calculation and interpretation

Use official original information as the basis for brand facts; creating materials or requesting corrections does not mean a citation has been obtained

import argparse, hashlib, json, re, math
from decimal import Decimal
from pathlib import Path

def json_stringify(value):
    if value is None or isinstance(value,(str,bool)):return json.dumps(value,ensure_ascii=False,separators=(',',':'))
    if isinstance(value,(int,float)):
        if not math.isfinite(value):raise ValueError('CONTEXT_NUMBER_NOT_FINITE')
        if value==0:return '0'
        if 1e-6<=abs(value)<1e21:
            return str(int(value))if int(value)==value else format(Decimal(repr(value)),'f')
        mantissa,exponent=format(float(value),'.16e').split('e')if isinstance(value,int)else repr(value).lower().split('e')
        mantissa=mantissa.rstrip('0').rstrip('.')if '.'in mantissa else mantissa
        return mantissa+'e'+('+'if int(exponent)>=0 else '-')+str(abs(int(exponent)))
    if isinstance(value,list):return '['+','.join(json_stringify(v)for v in value)+']'
    return '{'+','.join(json.dumps(k,ensure_ascii=False)+':'+json_stringify(v)for k,v in value.items())+'}'

def digest(value):
    raw=value if isinstance(value,str) else json_stringify(value)
    return hashlib.sha256(raw.encode()).hexdigest()
