5. When the user requests several independent tasks, list the method packs needed for each and follow the user's chosen order. If no order is given, ask the user to select one task first
6. If the index has no suitable method, say so. Do not invent IDs or filenames, or pretend to have read other methods

- Start with this conversation's attachments, background already provided and readable links specified by the user. If a link cannot be read, identify the missing content and ask for the file

- Distinguish product facts, brand claims, assumptions and unknowns. Preserve each number's period, unit, denominator and source location

- Keep examples quoted from teaching materials as examples. For current platform rules, read the official documentation itself or ask the user for the relevant official text
- Ask only for missing inputs that would affect this task's result. Do not ask again for information already supplied

# MK-085 | Expanding audiences for the same product


## Purpose

This skill delivers: **New user groups to test for the same product**

Products occurring in the same transaction do not establish psychological motives; a product pairing does not automatically prove cross-selling effectiveness

## Required inputs

Provide: Product capabilities and limits, current audience and uses, customer/market need signals, stock and costs; records of new-use orders if available

## Method

1. List demonstrated capabilities, limitations and current uses
2. Find different uses in customer wording, service records or market questions, then identify possible roles without inferring identity from age or one purchase
3. Check whether the existing product can complete each job, required conditions and counterexamples; retain unmet needs
4. Prioritize by need evidence and supply capacity, specify observable validation, and check cost/outcomes when actual orders exist

## Calculations and interpretation

Product selections and next-need proposals are candidates; check inventory, gross margin, existing buyers, and sales data
