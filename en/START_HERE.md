# Use the skills in an AI conversation

## Start your first task

Download and extract the English materials ZIP. Open a conversation in an AI tool that can read uploaded files, such as ChatGPT, Claude or Gemini. Upload `INDEX.md`, then paste the short starter prompt from [README.md](README.md) and describe your task

When the AI selects a method, find the `.md` file it names in `packs/`. Upload that method pack and the data for your task. Product information can be a document, a product-page PDF or an image; reports can be CSV files or spreadsheets. Use a format the current conversation can actually read

If your files are in Google Drive, you can also share a readable link to the individual file. The AI needs to read the complete method before using it. If it cannot open the link, download that same method pack and upload it to the conversation. A folder link does not load every file into the conversation

## Follow-up questions and different tasks

For a revision to the same task, say what needs changing. For a different task, the AI checks the uploaded index again. Upload the new method pack if its full text has not yet been read

For example, first calculate the contribution margin per box of cookies, then ask how to encourage one-time customers to buy again. The first task uses MK-059; the index then leads to MK-390. You can simply ask the new question without naming a method ID

In a new conversation, upload the index and the relevant method pack again. You can also upload your completed [brand context template](context/MARKETING_CONTEXT.template.md) to carry over useful background

## Usage limits or unread attachments

If your interface says you have reached its usage limit, save the materials and your current results, then resume when access is available. If a file appears uploaded but the AI has not read it, ask it to confirm the title and method name it can see before working on your task
