# Free materials and advanced services

The free edition is one collection of methods and references, organized by a public manifest. Match the language and version when obtaining materials through the repository or a download folder

| Free materials | Work handled by ThinkWithBlack MCP |
|---|---|
| Select a method from the index and manually upload its pack | Overall diagnosis, coordination and follow-through across methods |
| Analyze files supplied by the user | Connect accounts, retrieve data and keep it updated |
| Complete a specific piece of copy, calculation, analysis or plan | Make changes in accounts, websites or other systems |
| Follow up, add data and revise in the same conversation | Maintain long-term project state, schedules, monitoring and notifications |

The free methods retain their complete steps, required references, sources, output fields and quality checks. Maintainers build the materials from the public manifest so that downloads of the same language and version contain the same files
