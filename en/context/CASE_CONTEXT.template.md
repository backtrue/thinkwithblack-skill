# Case continuation summary

Keep one file per original request. The AI updates it from the actual task evidence. Provide it with the brand context and selected method pack in a new conversation

## Task and version

- task_id, summary revision and update time
- Original request verbatim, selected method and current stage
- Brand key, product and version, audience, market and period
- Context data IDs, versions and digests actually used in this task

## Intended outcome

- Desired outcome and current obstacle, each with sources
- Supporting evidence and its scope
- Untested assumptions, retaining their hypothesis status

## Approaches and choices

| Decision ID | Question | Prerequisites | Feasible options | Recommendation and sourced reason | Chosen answer and confirmation quote | Deliverable after the answer |
|---|---|---|---|---|---|---|

Reuse confirmed choices. Keep recommendations separate from pending decisions. When a prerequisite changes, mark dependent choices and outputs for review

## Next action and results

- Next action, expected output, owner and evidence
- New evidence that would change the recommendation
- User-reported results, period, sources and unavailable metrics
- Delivered output locations and actual content SHA-256

## Sources and corrections

| Source ID | URL or file location | Actual excerpt | Retrieval time and scope | SHA-256 |
|---|---|---|---|---|

Keep earlier versions, correction evidence and affected outputs, then continue from the latest version. Match the brand, original request and relevant context first. Ask which case is intended when several match. Retrieve long reports and complete history from their sources as needed
