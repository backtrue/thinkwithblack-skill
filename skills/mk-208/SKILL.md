# MK-208｜再行銷 Hero Post 評估

一般對話請上傳 `packs/mk-208.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**挽回用途的成效與素材角色**

歷史成功只支持候選與假說，不能把內容共同元素寫成已證實致勝原因

## 必要資料

請提供：貼文 ID、跨受眾成效、素材及種子名單品質

## 方法步驟

1. 再行銷 Hero Post 要看已互動／已瀏覽受眾是否能被同一貼文推進轉換
2. 與新客 Hero Post 分開評估，因受眾成熟度與任務不同
3. 仍同時看 CTR、互動、轉換與樣本量，不只看社群反應

## 計算與判讀

按貼文 ID 彙總並區分投放情境；高互動或高 ROAS 單一指標不足以保證可放大
