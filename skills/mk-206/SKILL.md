# MK-206｜Hero Post 候選篩選

一般對話請上傳 `packs/mk-206.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**含樣本量與多面向表現的候選**

歷史成功只支持候選與假說，不能把內容共同元素寫成已證實致勝原因

## 必要資料

請提供：貼文 ID、跨受眾成效、素材及種子名單品質

## 方法步驟

1. Hero Post 是被足夠廣告花費驗證，同時具有良好轉換、CTR 與互動，可跨受眾持續使用並累積 Social Proof 的主力貼文
2. 不要求自然互動，也不是只選 ROAS 最高；以 Post ID 為單位並把樣本量納入
3. 來源可來自高互動社群貼文、創作者社群能量或廣告煉蠱勝出結果

## 計算與判讀

按貼文 ID 彙總並區分投放情境；高互動或高 ROAS 單一指標不足以保證可放大
