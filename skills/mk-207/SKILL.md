# MK-207｜新客 Hero Post 評估

一般對話請上傳 `packs/mk-207.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**新客用途的成效與適用人群**

歷史成功只支持候選與假說，不能把內容共同元素寫成已證實致勝原因

## 必要資料


可用原始資料：相同貼文在不同新客受眾的成本、成熟成果與可比投放條件

## 方法步驟

1. 將 Post ID 的各次新客受眾測試分開，接上實際首購身分、花費、成熟訂單、頁面與優惠；首次進站不等於首次購買，未知購買史獨立列出
2. 高 CTR 或加購只支持訊息有反應；新客成交任務要看有效首購及相應成本。只在既有買家／暖名單成交，改列暖受眾用法
3. 同一貼文在原目標新客群成熟結果符合成本，先留在該群；另一可比新客群也成立、素材承諾可用且有供貨，才提出擴至相近新客的小範圍測試
4. 少量訂單中移除最大單便翻轉成本／貢獻判斷，維持有限額候選；花費額或觀察天數本身不保證樣本足夠。成本目標未給時交實際成本與條件，不自定目標
5. 後續購買史核對發現是舊客，剔除首購成果重算；新客群未重現則收回該群擴張，保留仍成立的原用法。缺件先取會改變身分或成本判斷的訂單紀錄

## 計算與判讀

首購成本＝該測試花費／可確認的有效首購人數；未知身分不併入分母。交付逐受眾成本、候選範圍與擴張／撤回條件

核對例（假設資料）：花費 3,000 元、6 位確認首購、上限 600 元，成本 500 元，保留原群；其中 3 位後來確認買過，重算 1,000 元，撤回基於首購達標的擴張建議
