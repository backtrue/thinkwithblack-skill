# MK-073｜營收缺口拆解

一般對話請上傳 `packs/mk-073.md`，其中已包含共用規則、本文及必要參考

方法修訂：2026-10-12｜Decision Model 試作

## 工作目的

回答一個決定：**這次營收下降或未達目標，應先檢查來客、成交還是客單？**

交付流量、成交率與客單的缺口分解，接著給出優先檢查方向、依據、下一步與回看條件。使用者已有明確比較期間或目標時直接沿用

## 必要資料與補問

先從已提供資料整理下列欄位，能計算的欄位直接算，缺少的才補問

| 必要資料 | 用途 |
|---|---|
| 比較期與本期，或目標與實際 | 說明要比較哪兩組數字；目標數字保留假設身分 |
| 兩期淨營收 | 計算營收差額，核對幣別、折扣、退款、運費及交易狀態的計入方式 |
| 兩期交易筆數 | 計算客單＝淨營收÷交易筆數 |
| 兩期流量與單位 | 計算成交率＝交易筆數÷流量；門市固定使用入店人次或同行組數，網站固定使用同一種流量定義 |
| 營業日、時段與資料來源 | 確認範圍可比，讓結論能回查原表或附件 |

已有同口徑成交率、客單與流量時，可以直接拆解，再與淨營收核對。成本、固定費與毛利只在使用者另問獲利時才需要；本題資料已足夠時完成營收判斷

依缺件接續：

- 只有營收：先算總差額，再問兩期交易與流量數值；流量單位已提供時直接沿用，尚未提供時才補問單位
- 已有營收與交易筆數：先算客單及交易變化。兩期交易筆數均大於 0 時，可先算交易變動合計＝(N1 − N0)×A0、客單差額＝N1×(A1 − A0)，N 為交易筆數；兩項加總核對營收差額。再補兩期流量與單位，把交易變動拆成來客與成交差額
- 只有本期：先問要和哪個期間或目標比較
- 期間長度或營業時段不同：先取可對齊的日期與時段；可先列總額、每日平均及營業日差異，待比較範圍確定後再排優先順序
- 口徑不一致：指出具體哪個欄位不同，要求對齊該欄位；已提供背景沿用
- 只問一般做法、沒有數字：交付下方決策表及最小紀錄表「日期／營業時段、流量與單位、交易筆數、淨營收、缺貨／未購／退換貨紀錄」，說明取得哪些數字後可以選分支

## 方法步驟

1. **拆解營收**：先固定期間、流量、交易與淨營收口徑，再算流量 × 成交率 × 客單。單位售價與客單依交易內容區分，購買多件時使用每筆交易的客單
2. **定位缺口**：比較目標與實際或兩期實績，依下方固定順序分解金額，再選決策分支。有同口徑曝光與點擊資料時，可往下拆曝光 × 點擊率＝點擊數；採用點擊作流量時，成交率分母也須為點擊數。網站工作階段與門市來客各按自己的定義計算
3. **接上決定**：交付優先檢查方向、支持證據、要核對的原因候選、下一步及回看條件。新資料改變前提時，更新計算與分支，連同原本的行動一起修正

## 計算與判讀

令比較期或目標為 0，本期或實際為 1；T＝流量，C＝成交率，A＝客單，R＝淨營收。先核對兩組 R＝T×C×A

固定使用「流量 → 成交率 → 客單」順序，逐一替換變數：

| 差額 | 計算式 |
|---|---|
| 流量差額 | (T1 − T0) × C0 × A0 |
| 成交率差額 | T1 × (C1 − C0) × A0 |
| 客單差額 | T1 × C1 × (A1 − A0) |
| 總差額 | 三項相加＝R1 − R0 |

保留正負號，以金額比較負向差額，正向差額另列為抵銷。多項同時變動時，這個固定順序決定交互變動如何分配；優先順序是查證起點，原因仍需紀錄支持

原始數值、單位、期間、來源與代入式一起保留。成交率以小數代入，對外可用百分比呈現；計算保留精度，最後才四捨五入。若加總對不上，先查期間、退款、交易狀態、流量分母及輸入數字的四捨五入差異，處理後再選分支

分母為零時，該比率記為無法計算，保留可確認的營收與交易事實。例如流量為正、交易為零，成交率為 0，客單無法計算，可先檢查未成交紀錄。各差額式的變數都已知時，該項可先列出；涉及未定義客單的項目標為無法計算，總營收差額另列，完整三項分解保留待補。流量為零則先核對營業與流量紀錄，取得可用資料後再拆解三項金額

## 決策分支

先處理必要資料缺件、零分母與口徑差異，再核對本題比較基準。資料可比且沒有營收缺口時，優先選「維持目前做法」，並列出正負抵銷；有營收缺口時才依來客、成交或客單排列查證順序。兩項以上為負向差額時，先用「多項下降」列排序，再接各項的檢查動作。使用者更正資料時，從受影響的資料重新核對

| 證據條件 | 本次決定 | 下一步查什麼 | 何時回看或改判斷 |
|---|---|---|---|
| 流量下降，成交率與客單持平或上升 | 先查來客缺口 | 依已有紀錄比較營業日、時段、通路或曝光／點擊；把缺口定位到可核對的區段 | 補齊區段資料或下一個可比期間後，重算三項差額 |
| 成交率下降，流量與客單持平或上升 | 先查成交缺口 | 看缺貨、未購詢問、接待或結帳紀錄；對照相同商品、時段或通路 | 紀錄支持某項原因後，列對應改善提案；下一個可比期間重算成交率與營收 |
| 客單下降，流量與成交率持平或上升 | 先查客單缺口 | 比較每筆件數、品類占比、折扣與退款，找出客單差異出現在哪裡 | 資料補齊後確認品項或訂單區段，重算客單與營收 |
| 兩項以上出現負向差額 | 按負向金額由大到小安排查證 | 先查最大負向項目的紀錄，並列其他負向與正向抵銷；同額並列，再按已有資料可查性安排先後 | 新資料改變金額排序，連同查證順序更新 |
| 只有營收與交易筆數，流量未知 | 先判讀交易與客單，補流量後再選來客或成交分支 | 索取同期間的來客或網站流量及單位 | 流量補齊後重新拆解三項差額 |
| 期間、分母、退款等口徑不符，或公式對不上 | 先對齊資料 | 指出不符欄位、差額與需要的原始紀錄 | 口徑對齊且加總可核對後再排查證順序 |
| 本題比較基準下沒有營收缺口 | 維持目前做法，回看下一個可比期間 | 列出變動與抵銷；使用者有指定目標時，仍須與該目標核對 | 出現新缺口，或使用者提供新目標時重判 |
| 使用者補充或更正資料 | 依更新後資料重新選分支 | 更新受影響的比率、三項金額、優先方向與行動，指出哪筆資料改變了判斷 | 以修正後的資料與回看條件續做 |

原因候選用查證動作表達，例如「對照缺貨日期與未購紀錄」。要提出調整時，連到已查到的具體證據及使用者可執行的範圍；店長感受、單一比率下降與金額排序各保留原本的證據性質

## 固定交付欄位

先用一段話說明「現在先查什麼、根據什麼、下一步做什麼、何時回看」，再用表格保留下列七欄。資料不足時，先交可算部分與必要補問；只問方法時交決策表與紀錄方式

| 順序 | 欄位 | 填寫方式 |
|---:|---|---|
| 1 | 輸入變數 | 本題使用的營收、流量、交易筆數、成交率與客單 |
| 2 | 數值 | 原始或計算數值；未知直接標示 |
| 3 | 單位與口徑 | 期間、幣別、流量分母及交易／退款定義 |
| 4 | 來源 | 原表、附件、使用者提供數字或明確標示的目標假設 |
| 5 | 計算式 | 代入值、三項差額與總額核對；不能計算的欄位指出缺件 |
| 6 | 結果 | 選中的分支、優先方向、下一步與回看條件 |
| 7 | 限制 | 會影響這次選分支的具體缺件或口徑差異；已齊全時寫「計算與選分支資料已齊」。原因與目標依據的待查證項目列入下一步 |

使用已知客群補充方法時，把組別差額接到同一份成果，指出先查哪個組別的紀錄；取得該組的流量與交易資料後，才進一步選來客、成交或客單分支

## MK-073 補充方法：已知客群營收差額

若提供互斥且涵蓋完整的組別與同口徑期間資料，優先使用實際淨營收；否則可用同一期間與訂單狀態口徑的訂單數 × 平均訂單金額估算各組營收。各組營收差額＝本期該組營收－比較期該組營收。各組差額加總應與總營收差額一致；若不一致，先查期間、分組、退款或口徑差異，不硬湊平

這是已知組別的算術拆解，不解釋組別為什麼變動，也不證明廣告造成變動。訂單數不等於顧客數；需分析顧客人數或首購／回購時，另取去重顧客 ID 與首次下單定義。若分類定義、退款／折讓、幣別或訂單狀態不一致，保留差異並先補齊口徑

### 補充驗收案例
**MK-073-C07｜新客與回購客營收差額**
案例資料：比較期新客 100 張訂單、平均訂單金額 1,200 元；回購客 80 張、1,800 元。本期新客 140 張、1,100 元；回購客 45 張、1,700 元。只有在期間、幣別、訂單狀態與分組定義一致，且新舊客組別互斥並涵蓋完整時，才作此算術拆解
預期：比較期新客營收 120,000 元、回購客 144,000 元、合計 264,000 元；本期分別為 154,000 元、76,500 元、合計 230,500 元。新客組差額 +34,000 元、回購客組 −67,500 元，合計 −33,500 元，與總差額一致。『張』按訂單數解讀，不推算顧客人數，不解釋原因或宣稱廣告因果

### 補充方法來源
- [Shopify Customers reports](https://help.shopify.com/en/manual/reports-and-analytics/shopify-reports/report-types/default-reports/customers-reports)：用於核對首次購買、回購顧客與顧客 cohort 的分組定義及報表口徑
- 組別差額公式是 ThinkWithBlack 依使用者提供的已分類數據所作的算術拆解；不宣稱為 Shopify 定義的通用歸因公式

## 核對案例

以下為虛構練習資料。除個別說明外，兩期營業期間、流量與交易定義相同，金額為新台幣淨營收

| 案例 | 比較期 → 本期 | 預期決策與核對重點 |
|---|---|---|
| D01 來客 | 1,000 人／100 筆／100,000 元 → 800 人／80 筆／80,000 元 | 流量差額 −20,000 元，其他為 0；先查來客區段 |
| D02 成交 | 1,000 人／100 筆／100,000 元 → 1,000 人／80 筆／80,000 元 | 成交率 10% → 8%，差額 −20,000 元；先查未購、缺貨與接待紀錄 |
| D03 客單 | 1,000 人／100 筆／100,000 元 → 1,000 人／100 筆／80,000 元 | 客單 1,000 → 800 元，差額 −20,000 元；先查品類、件數、折扣與退款 |
| D04 多項下降 | 1,000 人／100 筆／100,000 元 → 800 人／64 筆／57,600 元 | 三項依序 −20,000、−16,000、−6,400 元，合計 −42,400 元；先查來客，另列成交與客單 |
| D05 缺流量 | 100 筆／100,000 元 → 80 筆／80,000 元 | 客單持平、交易下降；補問流量與單位後再區分來客和成交 |
| D06 口徑不同 | 30 天入店人次 → 20 天同行組數 | 先對齊期間與流量定義 |
| D07 分母為零 | 本期 100 人／0 筆／0 元 | 成交率為 0，客單無法計算；先查未成交紀錄，保留可算部分 |
| D08 更正資料 | D02 的本期流量更正為 800 人，其餘不變 | 成交率回到 10%；改為先查來客，替換原本優先查成交的行動 |
| D09 沒有缺口 | 兩期皆為 1,000 人／100 筆／100,000 元，沒有更高目標 | 三項差額皆為 0；維持並回看下一可比期間 |
| D10 正向抵銷 | 1,000 人／100 筆／100,000 元 → 800 人／80 筆／104,000 元 | 流量 −20,000、成交 0、客單 +24,000 元；總額 +4,000 元，本題無缺口，列出抵銷 |
| D11 只有營收 | 100,000 → 80,000 元 | 先交差額 −20,000 元，再問兩期交易與流量 |
| D12 有目標 | 目標 1,000 人／100 筆／100,000 元，實際 800 人／80 筆／80,000 元 | 差額 −20,000 元；標明目標假設，先查來客與目標依據 |

沿用 MK-073-C07 核對已知客群差額。另問獲利而只提供部分成本時，列已知成本、尚缺項目與可算結果，依使用者的新工作重新查索引選方法
