# MK-383｜首次回購天數計算

一般對話請上傳 `packs/mk-383.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**第一與第二次有效購買間隔**

不同觀察期的RFM不可直接當同基準排名；任何名單匯出與使用另核對目的與授權

## 必要資料

請提供：經去識別處理的顧客、訂單、日期、金額及退款資料

## 方法步驟

1. 先篩出購買次數為 2 次的會員
2. 對每位會員計算第一次購買到第二次購買之間的天數
3. 再對這批回購天數計算平均值，作為第一次回購天數的基準
4. 講義的 Check 是持續降低第一次回購天數；沒有第二次購買的人不硬填成某個天數

## 計算與判讀

先定會員與有效訂單口徑、退款及期間；頻次以訂單而非品項列數計算
