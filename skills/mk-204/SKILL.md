# MK-204｜貼文 ID 辨識

一般對話請上傳 `packs/mk-204.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**可追溯貼文識別碼與格式檢查**

歷史成功只支持候選與假說，不能把內容共同元素寫成已證實致勝原因

## 必要資料

貼文完整 URL、預覽或原始連結、內容類型及可辨識的來源；已知 Post ID 可提供核對，不作為前置

## 方法步驟

1. 以 Post ID 作為 Hero Post 的核心識別，不以廣告名稱代替
2. 使用提供的貼文網址或預覽截圖；依 /posts/、story_fbid 或影片網址辨識 ID
3. 影片網址中的影片編號需依實際平台流程轉用；正式操作前核對現行介面

## 計算與判讀

識別碼保留原始字串，核對所屬粉絲專頁與貼文；影片編號、候選編號與已確認 Post ID 分開記錄，缺少平台確認時保留待確認

## 固定交付欄位

| 順序 | 欄位 | 填寫方式 |
|---:|---|---|
| 1 | 來源貼文網址或預覽 | 填入已提供來源、計算或明確未知 |
| 2 | 網址類型及辨識規則 | 填入已提供來源、計算或明確未知 |
| 3 | 候選識別碼及來源位置 | 填入已提供來源、計算或明確未知 |
| 4 | 格式檢查結果 | 填入已提供來源、計算或明確未知 |
| 5 | 已確認 Post ID 與確認依據 | 填入已提供來源、計算或明確未知 |
| 6 | 影片編號轉用或現行流程待確認 | 填入已提供來源、計算或明確未知 |

## 核對案例

**MK-204-A1｜只有含 /posts/ 的貼文 URL**

預期：由來源辨識候選 ID，不先要求使用者提供 ID

**MK-204-A2｜只有影片編號**

預期：保留內容類型及需核對的轉用流程，不直接冒充貼文 ID
