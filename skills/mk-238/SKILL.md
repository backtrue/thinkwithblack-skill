# MK-238｜搜尋需求語意聚類

一般對話請上傳 `packs/mk-238.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**依問題而非只靠字根分群**

保留原任務名稱與交付範圍；方法編撰性質：依母表任務與已核准入口要求編撰；不是宣稱逐字源自講義的新增規則；原來源為課程大綱，細部方法仍需核准／覆核。不得從這份草稿推導出未授權的產品行為、商業門檻或平台能力

帳戶看不到全部字詞時不得稱完整市場需求；同一詞在不同服務情境可有不同意義

## 必要資料

請提供：搜尋字詞、關鍵字、活動成效、頁面及需求假說

## 方法步驟

1. 使用真實 Search Terms，而不是只用 Keyword 假設，完成「搜尋需求語意聚類」
2. 課程大綱支持以 AI 聚類 Search Terms，整理 Query Cluster、Search Intent、問題主題與商業價值，並分成 Ads／SEO／Both／Ignore
3. 產出「依問題而非只靠字根分群」時保留原始搜尋字詞與對應證據；沒有真實 Search Terms 時，只能做方法規劃，不能宣稱市場已驗證
4. 大綱沒有定義固定聚類演算法、分數或商業價值門檻，因此不自行新增

## 計算與判讀

搜尋字詞報表未必涵蓋全部市場；資料不足先觀察，否定詞不可僅憑猜測
