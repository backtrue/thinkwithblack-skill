# MK-097｜教育型流量預算規劃

一般對話請上傳 `packs/mk-097.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**先理解再成交的資源用途**

歷史季節表現可作依據但不能保證重現；沒有使用者核准不建立付費排程或發布

## 必要資料

可用原始資料：本次教育任務、受眾原始問題、內容／頁面、可累積且可使用的名單或事件、製作與媒體費、總資源、承接結果及可承擔上限

## 方法步驟

1. 先定教育要讓誰理解哪件事、接到哪個真實行動，分開曝光、理解線索、有效名單與成交。沿用已核定任務，不用最後未成交否定原本只要解釋的內容，也不把曝光當成交
2. 讀實際問題與既有內容：問題已被承接且無需重做時保留資產；內容或頁面缺答案／行動入口先補。要累積名單時，確認資料可取得、可使用及會被後續哪項工作接手
3. 候選投入先列製作、媒體與其他費用，與總資源、常態任務和現金限制比較。無法支應或沒有可承接需求時暫緩；需求與承接成立時選有上限、期間及成果口徑的有限投入，不補通用教育預算百分比
4. 回看本次任務：有效教育／名單成果增加且成本可承擔，續做候選；只有低品質名單或承接中斷，換題／機制或先修承接；成本超出既定上限停該投入。是否接轉換取決於已觀察需求、可用商品與頁面，不只取決於曝光數
5. 交費用表、要驗證的原問題、觀察欄位與續做／調整／暫緩條件。新增客服問題、名單可用性或承接成果改變時重選；缺實績時交可填安排，不把安排寫成已達成

## 計算與判讀

名單任務的有效名單成本＝該任務全部費用÷同期間可使用的去重名單；有效名單為零時交已花費與零名單。原任務非名單取得時不強加此分母

核對例（假設資料）：內容費與媒體費合計600、收100筆名單，其中只有20筆符合任務與可使用，單筆有效成本30；若另確認其餘80筆也符合可用條件，成本改6，再依已定目標更新是否續做
