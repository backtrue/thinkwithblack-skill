# MK-083｜首購到回購商品接力

一般對話請上傳 `packs/mk-083.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**第一次購買後的商品路徑**

交易共現不是心理原因；商品搭配不自動證明交叉銷售成效

## 必要資料


可用原始資料：各次購買SKU與日期、使用週期、商品關係、成本與可聯絡狀態

## 方法步驟

1. 從首購 SKU、份量、用途、使用條件及已有後續訂單找下一個未滿足的需求；只求方向時以現有商品列條件路徑，不要求先算完整二購率／三購率
2. 同品為耗用品且接近有依據的使用週期，選補貨；主品尚可使用但已有相容的配件／下一階段需求，選跨品接力；用途無關、已買齊或商品不相容，不推硬湊的毛利款
3. 第二次與第三次都沿「上一筆解決什麼、下一個還缺什麼」推進，先排除已購與不適用者，再查庫存、每單貢獻及可聯繫資格
4. 補貨時間依實際份量／用量或同商品購買間隔，跨品則依實際使用階段；缺週期時列觸發條件並補一筆產品用法，不把 10～14 天變成固定提醒
5. 新訂單、尚未用完、改用途或退貨到來，替換下一段商品與時點；原本預計第二件已購，就移到下一個仍有證據的需求，不重複催同品

## 計算與判讀

若要量化路徑，某接續品購買率＝相同首購批次、同觀察窗內買接續品人數／完整原始首購群，包含未回購者；只看回購者的商品占比另列。每段交商品、適配證據、觸發、排除及改判紀錄

核對例（假設資料）：首購印表機後已明確表示要雙面裝訂，且有相容裝訂配件，列第二步候選；新訂單顯示配件已買，移除該推銷，只有耗材接近實際用量時才排耗材補貨

## 啟動條件與完整問題範圍

使用者要為已購顧客找後續購買方向、規劃從首購到品牌其他商品的接力，包含第二次及第三次購買時，直接使用本 Skill。原方法的持續購買不限於第二筆；以本店商品、需求及購買資料提出路徑，不要求另有名為三購的方法

真實問法 Q005：「銷售停滯，只有少數客人買第二、第三次，不想一直增加廣告投入，有什麼方向？」[原始提問](https://community.shopify.com/t/how-can-i-increase-repeat-customer-sales/271013/1)。保留不持續加廣告的限制；商品接力是原題可用的一個經營方向，作者認為廣告已優化仍是自述

先核對 SKU、商品成本、客群、購買紀錄與產品線；未取得時，按七個固定欄位交條件候選、適配依據及待補資料，不虛構商品、毛利、週期或銷售成果。未要求精確計量時，不把全歷史分群、二購率及三購率計算變成強制前置

只要安排已購一次者的第二件商品與提醒時機，依首購客二購計畫方法；若同時要求原因診斷、實際回購指標、因果效果、忠誠制度或平台設定，保留所有工作並找適用方法，不能以商品接力代替。一般求經營建議不等於要求證明營收已提升；本 Skill 不承諾效果
