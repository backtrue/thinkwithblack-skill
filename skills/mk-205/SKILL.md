# MK-205｜同貼文成效彙總

一般對話請上傳 `packs/mk-205.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**跨廣告的貼文層級成效**

歷史成功只支持候選與假說，不能把內容共同元素寫成已證實致勝原因

## 必要資料

請提供：貼文 ID、跨受眾成效、素材及種子名單品質

## 方法步驟

1. 同一 Post ID 可能被多個廣告／受眾使用，評估時要以 Post ID 彙總花費、CTR、互動與轉換
2. 不只看單一廣告列，避免把同一貼文的社群能量拆散判讀
3. 彙總時保留新客／再行銷與流量／轉換任務差異，不能把不同目的直接混成一個 ROAS

## 計算與判讀

按貼文 ID 彙總並區分投放情境；高互動或高 ROAS 單一指標不足以保證可放大
