# MK-205｜同貼文成效彙總

一般對話請上傳 `packs/mk-205.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**跨廣告的貼文層級成效**

歷史成功只支持候選與假說，不能把內容共同元素寫成已證實致勝原因

## 必要資料

Post ID 與廣告列對照、同期間花費、曝光、同定義點擊／互動／轉換原值、任務與歸因窗

## 方法步驟

1. 以 Post ID 對齊各廣告列，先排除重複匯出，固定期間、點擊或互動定義、任務與歸因窗
2. 在可相加且互斥的同口徑列加總花費、曝光、點擊及有效結果，再用分子總和除以分母總和重算比率；不相加或平均各列 CTR
3. 新客與再溝通、流量與成交任務分列；轉換若有跨列歸因重疊，保留平台口徑，不能稱去重真實訂單
4. 交原始加總、公式及結果，分母零時保留未定義

## 計算與判讀

CTR＝同定義點擊總和÷曝光總和；CPC＝花費總和÷同定義點擊總和；成交成本＝同口徑花費÷對應有效成交。先保留 CTR 的點擊種類與百分比單位

## 固定交付欄位

| 順序 | 欄位 | 填寫方式 |
|---:|---|---|
| 1 | Post ID 與來源廣告列 | 填入已提供來源、計算或明確未知 |
| 2 | 任務、期間及歸因窗 | 填入已提供來源、計算或明確未知 |
| 3 | 花費與曝光總和 | 填入已提供來源、計算或明確未知 |
| 4 | 各類點擊、互動與成交原值 | 填入已提供來源、計算或明確未知 |
| 5 | 分子分母及公式 | 填入已提供來源、計算或明確未知 |
| 6 | 重算結果 | 填入已提供來源、計算或明確未知 |
| 7 | 重複或不可合併項 | 填入已提供來源、計算或明確未知 |
| 8 | 判讀 | 填入已提供來源、計算或明確未知 |

## 核對案例

**MK-205-A1｜同口徑兩列：100曝光10點擊、900曝光9點擊**

預期：CTR＝19/1000＝1.9%，不是兩列 CTR 平均5.5%

**MK-205-A2｜兩列屬不同點擊定義**

預期：分開計算，不相加為同一 CTR
