# MK-241｜搜尋字詞轉商品頁補強

一般對話請上傳 `packs/mk-241.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**既有頁面未回答的需求**

帳戶看不到全部字詞時不得稱完整市場需求；同一詞在不同服務情境可有不同意義

## 必要資料

交易或行動型搜尋字詞與來源、商品或服務頁原文及 URL、產品事實、價格資格與可提供行動；成效作已有的優先序證據

## 方法步驟

1. 交易／行動型字詞優先檢查商品頁、服務頁或預約頁是否直接回答價格、規格、資格、優惠與 CTA
2. 若高意圖字詞已有流量但頁面沒回答，先補頁面承接，不只提高出價
3. 講義 7 日行動清單建議先挑 3 個高意圖字詞改寫落地頁或 FAQ，作為最小閉環

## 計算與判讀

搜尋字詞報表未必涵蓋全部市場；資料不足先觀察，否定詞不可僅憑猜測

| 順序 | 欄位 | 填寫方式 |
|---:|---|---|
| 1 | 原始 query 與意圖 | 填入已提供來源、計算或明確未知 |
| 2 | 頁面 URL 及原文位置 | 填入已提供來源、計算或明確未知 |
| 3 | 缺少的答案 | 填入已提供來源、計算或明確未知 |
| 4 | 實際補強稿 | 填入已提供來源、計算或明確未知 |
| 5 | 支持證據及條件 | 填入已提供來源、計算或明確未知 |
| 6 | CTA 與承接行動 | 填入已提供來源、計算或明確未知 |
| 7 | 優先序依據 | 填入已提供來源、計算或明確未知 |
| 8 | 待確認 | 填入已提供來源、計算或明確未知 |
