# MK-209｜高互動低成交貼文診斷

一般對話請上傳 `packs/mk-209.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**互動與商業任務的落差**

歷史成功只支持候選與假說，不能把內容共同元素寫成已證實致勝原因

## 必要資料

請提供：貼文 ID、跨受眾成效、素材及種子名單品質

## 方法步驟

1. 高互動但低成交時，不直接判定為 Hero Post
2. 檢查 CTR 是否高、ATC／Purchase 是否跟上，以及頁面承接／受眾任務是否一致
3. 若只帶互動不帶商業結果，可保留作互動／教育資產，但不當成轉換主力

## 計算與判讀

按貼文 ID 彙總並區分投放情境；高互動或高 ROAS 單一指標不足以保證可放大
