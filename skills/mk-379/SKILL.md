# MK-379｜RFM 分數計算

一般對話請上傳 `packs/mk-379.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**可重算的分數與原始依據**

不同觀察期的RFM不可直接當同基準排名；任何名單匯出與使用另核對目的與授權

## 必要資料

可用原始資料：顧客／有效訂單／退款、參考日與完整觀察窗；核准R、F、M分數區間（含邊界是否包含、方向、M總額或平均額、規則版本），以及需命名時的代碼對照

## 方法步驟

1. 先計原始R＝參考日距最後有效購買的日數，F＝指定期間去重有效訂單數，M＝核准期間淨總額或平均額；三者保留日期、期間、有效規則及原始明細
2. 逐軸套本案核准區間，檢查每個原始值恰好命中一列。重疊列交規則衝突，沒有命中交未映射，不補最接近分數；沒有有效購買時R未定義，依核准無購買規則處理
3. 課堂三位代碼按R、F、M順序串接各自1至5分，例如5、4、3組成543。Total Score在此是分類代碼，不是5＋4＋3＝12，也不是加權總價值；使用不同分數範圍時改用本案核准編碼與對照
4. 交每位會員的原始RFM、命中區間、三個分數、代碼及規則版本。要命名時只套同版本核准對照；沒有對照就保留已算分數與代碼，不猜忠誠或沈睡
5. 新訂單、退款、參考日、區間邊界或M定義變更時重算受影響分數與分類，保留改前值；不同觀察窗／版本不直接當成會員變好或變差

## 計算與判讀

可填的五階區間表（採用前填入本案核准的遞增切點與版本；品牌已有表時直接使用該表）

| 分數 | R日數（越小越近期） | F有效訂單數 | M核准金額 |
|---:|---|---|---|
| 1 | R ≥ r4 | F < f1 | M < m1 |
| 2 | r3 ≤ R < r4 | f1 ≤ F < f2 | m1 ≤ M < m2 |
| 3 | r2 ≤ R < r3 | f2 ≤ F < f3 | m2 ≤ M < m3 |
| 4 | r1 ≤ R < r2 | f3 ≤ F < f4 | m3 ≤ M < m4 |
| 5 | 0 ≤ R < r1 | F ≥ f4 | M ≥ m4 |

每軸切點需遞增且有單位；表中F以有有效購買者為對象，零購買另套核准規則。沒有切點時交原始值與待定表，不推算通用門檻

核對例（假設已核准切點）：R為30，r1＝31、r2＝61、r3＝91、r4＝121，得5分；F為4，f1＝2、f2＝3、f3＝4、f4＝5，得4分；M為250，m1＝100、m2＝200、m3＝300、m4＝400，得3分；代碼543。r1改成30後，R＝30命中30 ≤ R < 61，改4分，代碼443
