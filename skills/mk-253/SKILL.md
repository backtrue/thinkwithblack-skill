# MK-253｜商品描述完整性檢查

一般對話請上傳 `packs/mk-253.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**功能、用途與限制資訊缺漏**

ID無法一對一匹配時保留未匹配，不猜對應；沒有完整事件樣本不捏造匹配率

## 必要資料

目錄平台、逐 SKU／變體原始 description、商品頁及正式功能／用途／適用限制資料，必要的現行欄位規格

## 方法步驟

1. 逐 SKU／變體對回實際商品，保留原 description 與來源
2. 分別核對功能、使用情境及適用限制，列已涵蓋、缺漏、錯誤或資料未知；限制不因不利促銷而省略
3. 依已確認事實交付可使用的新描述，保留條件與變體差異，不添加未證實的效果、優惠或用途
4. 將原值、缺口、修改文字及來源逐項對照，再核對當次平台要求；不自行加入固定字數或保證排名的模板

## 計算與判讀

商品規格與價格以商品資料為準；目錄欄位及拒登規則在製作時驗證

## 固定交付欄位

| 順序 | 欄位 | 填寫方式 |
|---:|---|---|
| 1 | SKU／變體與商品來源 | 填入已提供來源、計算或明確未知 |
| 2 | 原 description | 填入已提供來源、計算或明確未知 |
| 3 | 功能／用途／限制逐項核對 | 填入已提供來源、計算或明確未知 |
| 4 | 缺口或錯誤 | 填入已提供來源、計算或明確未知 |
| 5 | 建議新 description | 填入已提供來源、計算或明確未知 |
| 6 | 修改依據與規格檢查 | 填入已提供來源、計算或明確未知 |
| 7 | 待確認事實 | 填入已提供來源、計算或明確未知 |

## 核對案例

**MK-253-A1｜正式資料註明僅適用室內，原描述沒有此條件**

預期：補入室內使用限制並保留實際功能，不擴寫為全天候戶外適用
