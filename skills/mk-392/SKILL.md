# MK-392｜高價值會員新品優先

一般對話請上傳 `packs/mk-392.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**適用會員與新品溝通方案**

客戶分群與真正接受行銷訊息的資格是兩件事

## 必要資料

請提供：會員群組、商品週期、可用優惠及訊息接收權限

## 方法步驟

1. 對忠誠會員提供能維持尊榮感的新品／特殊企劃優先權
2. 講義示例包含新品 VIP 專屬優惠價、線下封館活動優先資格、特別企劃活動優先資格
3. 高潛力會員則可用經典款優先體驗；不同會員層級不要共用完全相同權益

## 計算與判讀

回購提醒以購買週期與同意聯繫條件為準；本目錄不會實際發訊

| 順序 | 欄位 | 填寫方式 |

| 1 | 顧客群 | 原始證據、方法中間結果或明確未知；不得補造 |
| 2 | 購買證據 | 原始證據、方法中間結果或明確未知；不得補造 |
| 3 | 經營任務 | 原始證據、方法中間結果或明確未知；不得補造 |
| 4 | 觸發／時間 | 原始證據、方法中間結果或明確未知；不得補造 |
| 5 | 訊息與商品 | 原始證據、方法中間結果或明確未知；不得補造 |
| 6 | 可用管道 | 原始證據、方法中間結果或明確未知；不得補造 |
| 7 | 排除條件 | 原始證據、方法中間結果或明確未知；不得補造 |
| 8 | 衡量 | 原始證據、方法中間結果或明確未知；不得補造 |
