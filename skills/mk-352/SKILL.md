# MK-352｜第三方內容補強優先序

一般對話請上傳 `packs/mk-352.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**缺漏、影響與可處理性的排序**

品牌被提及、被引用與介紹正確是不同結果，不能互相代替

## 必要資料


可用原始資料：目標問題、實際搜尋與引用頁、品牌錯誤內容、可聯絡方式與所需資源

## 方法步驟

1. 逐頁讀核心問題下的第三方實際內容，記品牌出現位置、比較條件、錯誤原句與可支持的品牌原始資料；缺席與寫錯分開
2. 會使讀者對重要適用條件、服務能力或產品事實做錯選擇，且有可提供的更正證據，列高優先修正；品牌單純缺席但確實符合該文收錄範圍，列補充候選
3. 文章問題與品牌任務無關、品牌不符合收錄條件或沒有能支持的資料，列低優先／不接洽；不能以「沒提我」要求所有頁面加入品牌
4. 同優先層再比較真實讀者需求頻率、已有曝光紀錄、可更正範圍與準備成本；未知流量／AI 使用情況保留未知，不自造影響分數。先取會改變層級的錯句原文或收錄規則
5. 對方改正、文章條件變動或品牌本身資料更新後重排；已更正者移出修正列，未獲引用不能反推改正無價值或保證再加內容有效

## 計算與判讀

交付每頁「讀者會做的選擇、目前寫法、直接證據、修正／補充／略過、優先原因、移出條件」；接洽只產草稿及資料，實際聯繫另依使用者授權

核對例（假設資料）：比較文寫品牌不支援到府，實際已有該地區正式服務，列錯誤修正；查到文章限定離島而品牌只服務本島，撤回錯誤標籤與高優先接洽
