# MK-380｜RFM 客群命名

一般對話請上傳 `packs/mk-380.md`，其中已包含共用規則、本文及必要參考

## 工作目的

這個技能交付：**忠誠、潛力、待喚回等分群定義**

不同觀察期的RFM不可直接當同基準排名；任何名單匯出與使用另核對目的與授權

## 必要資料

可用原始資料：已核對的R／F／M分數與三位代碼、區間／觀察窗版本、品牌核准類型映射；採原講義示例時使用本文內嵌表並保留未明確項目

## 方法步驟

1. 先確認代碼是R、F、M依序組合及其規則版本。品牌已有核准映射時以該表為準；要用講義示例時列明來源及目前核准使用，不把原課堂分類當成所有品牌既定政策
2. 逐代碼精確比對類型表，恰好一個明確匹配才命名。沒有匹配交未映射，多重匹配交衝突；不由總和、最相近代碼或所有未列者補成沈睡
3. 使用下方原表時，明確三位代碼可以比對；原文511.423與1~缺少無歧義定義，保留原記法及待核准展開，不自動拆成511、423或全部1開頭會員
4. 交原始RFM、分數、代碼、命中列、分類、表版本與活動目的。原表行銷工具只列候選，實際聯絡按會員接收資格與需求決定，分群本身不等於可發訊
5. 區間、M口徑、觀察窗或映射修改時重算分類；僅修映射時用相同已核對代碼重新比對。新資格與需求再調候選動作，不沿用舊群組硬推優惠
