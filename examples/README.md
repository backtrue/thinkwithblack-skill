# 虛構練習資料

以下商品、數字與顧客情境均為練習資料

1. [商品事實](product-facts.md)：先問「請幫我整理這個杯子能使用的商品事實與缺件」；預期選 MK-001
2. [餅乾成本](cookie-costs.md)：問「每賣出一盒餅乾，扣掉這些成本後還剩多少錢」；預期選 MK-059，結果為 190 元
3. 做完成本題，先只問「我想讓只買過一次餅乾禮盒的客人再買第二次，幫我安排聯絡時間、內容與成效追蹤」；預期重新選 MK-390 並要求全文。再上傳該方法包與 [二購情境](cookie-repeat.md)
4. [檔期預算與獲利練習](event-forecast.md)：估計歷史倍率、計算預估與目標
