# ThinkWithBlack｜365 個免費 AI 行銷 Skills

**一天一個 Skill，解決一個行銷問題**

365 份可上傳的行銷方法，從商品特色、文案、毛利到會員經營。把問題交給 AI，讓它先選方法，再依你提供的資料完成工作

免費版包含 **thinkwithblack-skills 與 Google Drive 提供的同一套內容**：方法索引、完整方法包、必要參考、範例與使用說明。兩個入口共用版本與公開清單

## 三步開始

1. 下載並解壓縮教材包，開啟一般 AI 對話，上傳 [INDEX.md](INDEX.md)
2. 貼上下面這段簡短指示，再說明你的問題
3. AI 指出需要的檔名後，上傳對應的 `packs/*.md` 及本題資料，讓它開始處理

> 請讀取附件索引。後續每次需求改變，先從既有索引選擇適用方法；若還沒讀到該方法全文，請指出名稱及方法包路徑，要求我上傳後再執行。索引不等於方法全文。我的問題是：【填入問題】

方法包已合併共用規則、完整方法、必要參考與授權，不用複製整篇內容，也不用另外找齊附件。索引與方法包各上傳一次即可；同一對話換題時，讓 AI 再依索引找方法
